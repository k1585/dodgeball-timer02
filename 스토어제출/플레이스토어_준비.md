## 2. 두 파일을 인터넷에 올리기

Play Console은 **접속 가능한 주소(URL)** 를 요구합니다. 파일만으로는 안 됩니다.

GitHub Pages가 가장 간단합니다 (무료):

1. GitHub에 공개 저장소를 하나 만듭니다
2. 두 HTML 파일을 올립니다
3. Settings → Pages → Source를 `main` 브랜치로 지정
4. 몇 분 뒤 아래 주소가 생깁니다

```
https://<아이디>.github.io/<저장소이름>/개인정보처리방침.html
https://<아이디>.github.io/<저장소이름>/계정삭제요청.html
```

> 한글 파일명이 불편하면 `privacy.html`, `delete.html`로 바꿔도 됩니다.

## 3-1. 점검 결과 (실측)

앱을 돌려 기기에 실제로 저장되는 항목과 외부 통신을 확인했습니다.

**저장되는 개인정보** — 방침에 고지한 내용과 일치합니다.
```
계정   : 이름, 비밀번호(pw/pwSaved), 가입·동의일시, 만14세미만 여부,
         보호자 성함, 보호자 연락처, 참여한 반 코드와 반에서 쓰는 이름
반     : 반 이름, 반 코드, 선생님 이름, 학생 명단, 숙제(제목·기한·설명)
제출물 : 사진, 학생 쪽지, 상태, 반려 사유, 지각일수
일정   : 제목, 기간, 선생님 이름
```

**외부 네트워크 요청: 0건** — 아무것도 기기 밖으로 나가지 않습니다.
Data safety를 "데이터 수집 안 함"으로 신고하는 근거가 됩니다.

## 3-2. 아직 남아 있는 법적 미비점 ⚠️

아래 세 가지는 **아직 해결되지 않았습니다.**

### (1) 비밀번호를 되돌릴 수 있게 저장하고 있음 — 가장 문제

관리자 화면에서 비밀번호를 **확인**할 수 있게 해 달라고 하셔서, 해시와 별도로
되돌릴 수 있는 형태(`pwSaved`)로도 저장하고 있습니다.

그런데 「개인정보의 안전성 확보조치 기준」은 비밀번호를 **복호화되지 않는
일방향 암호화**로 저장하도록 요구합니다. 지금 방식은 이 기준에 어긋납니다.

**해결하려면** 관리자의 '비밀번호 확인' 기능을 빼고 '초기화'만 남기면 됩니다.
(초기화는 `@abcd1234`로 바꾸는 방식이라 규정상 문제가 없습니다.)
말씀 주시면 바로 바꿔 드리겠습니다.

### (2) 보호자 동의의 본인 확인 절차가 없음

만 14세 미만 가입 시 보호자 성함·연락처를 받고 동의 체크를 받지만,
**정말 보호자가 동의했는지 확인하는 절차가 없습니다.** 아이가 혼자 체크할 수 있습니다.

시행령은 법정대리인에게 문자·이메일·신용카드 등으로 확인받도록 정하고 있는데,
서버가 없으면 문자나 메일을 보낼 수 없어 지금 구조로는 구현이 불가능합니다.

**파이어베이스를 붙일 때** 보호자 이메일로 확인 링크를 보내는 방식으로 해결해야 합니다.

### (3) 서비스 이용약관이 없음

개인정보처리방침만 있고 이용약관이 없습니다. Play 심사 필수 항목은 아니지만,
계정을 만들고 콘텐츠를 올리는 서비스라면 보통 함께 둡니다.
(필요하시면 만들어 드릴 수 있습니다.)

## 4. 아직 남은 문제 (스토어 정책 밖이지만 중요)

### 서버가 없어 앱으로선 작동하지 않음
선생님 폰과 학생 폰은 저장소가 따로입니다. 반 코드를 입력해도 상대 기기의 반을 찾을 수 없습니다.
**심사를 통과해도 실제로는 쓸 수 없으므로, 출시 전에 파이어베이스 연동이 반드시 필요합니다.**

### 관리자 비밀번호
소스에서 평문은 뺐고 관리자 화면에서 바꿀 수 있게 했지만, 네 자리 숫자는 앱을 뜯으면 금방 맞춰집니다.
**지나가다 눌러보는 사람을 막는 수준**이지 진짜 잠금이 아닙니다. 서버가 생기면 관리자 인증도 서버로 옮겨야 합니다.

### 웹뷰 래핑 반려 위험
HTML을 그대로 감싸기만 하면 "최소 기능" 정책으로 반려될 수 있습니다.
서버 연동 후 **PWA → TWA(Bubblewrap)** 방식을 권합니다.

### 앱 품질 (심사 반려보다는 혹평 요인)
- 안드로이드 뒤로가기: 지금은 홈에서 뒤로 누르면 앱이 종료됩니다
- 노치·제스처바: `safe-area-inset` 대응이 없어 화면이 가릴 수 있습니다
- 웹뷰에서 카메라 버튼: 네이티브 래퍼에 `onShowFileChooser` 연결이 필요합니다

## 5. 출시 절차 (개인 개발자 계정)

1. 개발자 계정 등록 ($25, 1회)
2. 앱 만들기 → 스토어 등록정보 (아이콘 512px, 그래픽 1024×500, 스크린샷 2장 이상)
3. 위 3번 항목 전부 입력
4. **비공개 테스트: 테스터 20명 이상 × 14일 연속** — 개인 계정은 이걸 마쳐야 프로덕션 신청이 열립니다
5. 프로덕션 심사 (보통 며칠 ~ 2주)

> 4번은 2023년 이후 개인 계정에 생긴 요건입니다. 정책은 자주 바뀌니 등록 시점에 Play Console 안내를 다시 확인하세요.
