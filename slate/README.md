# 🏀 농구 슬레이트

농구 경기 촬영 시작/끝에 패드로 보여주는 슬레이트 웹앱입니다. 파일 하나(`index.html`)로 동작합니다.

- 주소(배포 후): https://k1585.github.io/dodgeball-timer02/slate/
- 해야 할 설정: [CHECKLIST.md](CHECKLIST.md)
- 기본 비밀번호: `4242`

## 기능
- **홈**: 대회 목록, 통계(대회/경기/점수 미입력), 검색(대회코드 · 경기코드 · 어웨이팀 · 대회명), "점수 미입력" 필터
- **대회**: 날짜별 경기 목록, 점수 없는 경기는 빨간색, 카드의 🎬 버튼으로 바로 슬레이트
- **새 대회 추가**: 대회정보 + 첫 경기 / **새 경기 추가**: 경기정보부터 (대회정보 유지)
- **코드**: 대회코드·경기코드 모두 `#5자리` 자동 생성, 전체에서 중복 없음
- **점수**: +/− 버튼 또는 직접 입력, 승리팀 자동 표시
- **저장 규칙**: 점수·메모 외 모든 항목 필수. 나가기 시 저장 안 하고 나갈지 확인
- **슬레이트 모드**: 대회코드/경기코드만 가로 풀화면, 화면 꺼짐 방지, 두 번 탭하면 복귀
- **잠금**: 보기·검색은 누구나, 추가·수정·삭제는 비밀번호 (⚙️에서 변경)
- **백업**: ⚙️ → CSV(엑셀) 내보내기, 백업 파일 저장/불러오기

## 저장 방식
> 현재 **Firebase 연동 꺼짐** (`USE_FIREBASE = false`) — 이 기기(localStorage)에만 저장합니다.

Firebase Realtime Database의 `basketballSlate` 위치에 저장합니다.
Firebase에 접근할 수 없으면 자동으로 **이 기기(localStorage)** 에 저장하고(오른쪽 위 빨간 점),
나중에 연결되면 기기에 있던 기록을 자동으로 올립니다.

다른 Firebase 프로젝트를 쓰려면 앱의 ⚙️ → **Firebase 연결** 에 `firebaseConfig` 를 붙여넣거나,
`index.html` 위쪽의 `DEFAULT_FIREBASE` 값을 바꾸세요.

> 참고: 비밀번호는 화면 잠금 용도입니다. 데이터베이스 규칙이 공개(`.read/.write: true`)라서
> 주소를 아는 사람은 데이터에 접근할 수 있습니다. 민감한 정보는 메모에 넣지 마세요.
