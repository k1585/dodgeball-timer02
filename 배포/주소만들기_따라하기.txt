주소 만들기 — 따라 하기
====================================

앱을 인터넷 주소로 만들어서, 휴대폰과 학생들이 접속할 수 있게 하는 과정입니다.
처음부터 끝까지 10~15분 걸립니다.

무료이고, 한 번 만들면 계속 씁니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
왜 필요한가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

지금은 파일을 폰으로 보내서 열면 로그인이 되지 않습니다.
안드로이드가 파일을 "content://" 라는 방식으로 여는데,
그 상태에서는 서버와 통신을 할 수 없기 때문입니다.

주소(https://...)로 접속하면 이 문제가 없어집니다.
카메라 촬영도 주소로 접속했을 때가 확실합니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
준비물
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] 컴퓨터 (폰으로도 되지만 화면이 좁아 불편합니다)
[ ] 구글 로그인 (파이어베이스 만들 때 쓰신 그 계정)
[ ] 오늘의숙제.html 파일  ← 대화창에서 내려받아 두세요

파일이 어디 있는지 기억해 두세요. 보통 "다운로드" 폴더입니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1단계 · Cloud Shell 열기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1-1. 브라우저에서 아래 주소로 갑니다.

     console.cloud.google.com

1-2. 화면 맨 위 오른쪽에 아이콘이 여러 개 있습니다.
     그중 [>_] 모양을 찾아 누르세요.
     ("Cloud Shell 활성화"라는 설명이 뜹니다)

1-3. 화면 아래쪽에 검은 창이 열립니다.
     처음이면 "프로비저닝 중..." 같은 글이 나오며 30초쯤 걸립니다.

1-4. 준비가 끝나면 이런 줄이 보입니다.

     kimnui2012@cloudshell:~ (today-homework)$

     ↑ 괄호 안이 today-homework 인지 확인하세요.
       다르면 아래를 붙여넣고 엔터:

       gcloud config set project today-homework

✅ 여기까지 되면 1단계 끝.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2단계 · 작업할 폴더 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

검은 창을 한 번 클릭한 다음, 아래 줄을 복사해서 붙여넣고 엔터.

   mkdir -p ~/todayhw/public && cd ~/todayhw && pwd

무슨 뜻이냐면:
   mkdir  = 폴더를 만든다
   cd     = 그 폴더로 들어간다
   pwd    = 지금 어디인지 보여준다

나와야 할 결과:

   /home/kimnui2012/todayhw

✅ 이 줄이 나오면 2단계 끝.

※ 붙여넣기가 안 되면: 검은 창 안에서 마우스 오른쪽 클릭 → 붙여넣기
  또는 Ctrl + Shift + V


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3단계 · 앱 파일 올리기  ← 여기가 핵심
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3-1. 검은 창의 오른쪽 위를 보면 점 세 개 [⋮] 가 있습니다.
     (휴지통, 새 탭 같은 아이콘들 옆입니다)

3-2. [⋮] 를 누르면 메뉴가 뜹니다. "업로드" 를 고르세요.
     (영어면 "Upload")

3-3. 작은 창이 뜹니다. "파일" 을 고르고 → "찾아보기"
     → 내려받아 둔 오늘의숙제.html 을 고릅니다.

3-4. "업로드" 를 누르면 잠깐 기다린 뒤 완료됩니다.

     ※ 파일을 검은 창 위로 그냥 끌어다 놓아도 올라갑니다.

3-5. 올라간 파일을 제자리에 놓습니다. 아래를 붙여넣고 엔터:

   mv ~/오늘의숙제.html ~/todayhw/public/index.html && ls -l ~/todayhw/public/

무슨 뜻이냐면:
   mv = 파일을 옮기면서 이름을 index.html 로 바꾼다
        (웹에서는 첫 화면 파일 이름이 index.html 이어야 합니다)

나와야 할 결과 (숫자는 조금 달라도 됩니다):

   -rw-r--r-- 1 kimnui2012 kimnui2012 315548 ... index.html

✅ index.html 이 보이고 숫자가 30만 언저리면 3단계 끝.

⚠ "mv: cannot stat ..." 오류가 나면
   파일이 다른 이름으로 올라간 것입니다. 아래로 확인하세요:

   ls ~

   목록에서 실제 파일 이름을 확인하고, 그 이름으로 다시 하세요. 예:

   mv ~/오늘의숙제\(1\).html ~/todayhw/public/index.html


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4단계 · 설정 파일 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"어느 폴더를 인터넷에 올릴지" 알려주는 짧은 설정입니다.

아래를 여러 줄 통째로 복사해서 한 번에 붙여넣고 엔터:

   cd ~/todayhw
   cat > firebase.json <<'EOF'
   {
     "hosting": {
       "public": "public",
       "ignore": ["firebase.json", "**/.*"]
     }
   }
   EOF
   cat firebase.json

마지막 줄(cat)이 방금 만든 내용을 다시 보여줍니다.
{ 로 시작해서 } 로 끝나는 내용이 나오면 정상입니다.

✅ 내용이 그대로 나오면 4단계 끝.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5단계 · 인터넷에 올리기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5-1. 파이어베이스 도구가 있는지 확인합니다.

   firebase --version

   숫자(예: 13.x.x)가 나오면 다음으로.

   "command not found" 가 나오면 설치부터:

   npm i -g firebase-tools

   1~2분 걸립니다. 끝나면 다시 firebase --version 으로 확인.

5-2. 로그인합니다. (전에 하셨으면 건너뛰어도 됩니다)

   firebase login --no-localhost

   - 긴 주소가 하나 나옵니다 → 복사해서 브라우저 새 탭에 붙여넣기
   - 구글 로그인 → "허용"
   - 화면에 나온 인증 코드를 복사
   - 검은 창에 붙여넣고 엔터

   "✔ Success! Logged in as ..." 가 나오면 됩니다.

5-3. 드디어 올립니다.

   cd ~/todayhw
   firebase deploy --only hosting --project today-homework

나와야 할 결과:

   === Deploying to 'today-homework'...
   i  deploying hosting
   i  hosting[today-homework]: beginning deploy...
   i  hosting[today-homework]: found 1 files in public
   ✔  hosting[today-homework]: file upload complete
   ✔  hosting[today-homework]: release complete

   ✔  Deploy complete!

   Hosting URL: https://today-homework.web.app

✅ 맨 아래 Hosting URL 이 나오면 끝입니다. 그게 앱 주소입니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6단계 · 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6-1. 컴퓨터 브라우저에서 그 주소를 열어 봅니다.
     "만나서 반가워요" 화면이 나오면 성공.

6-2. 휴대폰 크롬으로도 그 주소를 엽니다.

     확인할 것:
     [ ] 주소창이 https://today-homework.web.app  (content:// 아님)
     [ ] "앱 주소로 열어 주세요" 안내가 안 뜬다
     [ ] 선생님 회원가입이 된다  ← 어제 멈췄던 부분
     [ ] 반을 만들 수 있다
     [ ] 사진 촬영 버튼을 누르면 카메라가 열린다

6-3. 폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.
     크롬 메뉴(점 세 개) → "홈 화면에 추가"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
나중에 앱을 고쳤을 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

새 오늘의숙제.html 을 받으면 3단계와 5-3만 다시 하면 됩니다.

   (⋮ → 업로드로 새 파일 올린 뒤)
   mv ~/오늘의숙제.html ~/todayhw/public/index.html
   cd ~/todayhw
   firebase deploy --only hosting --project today-homework

주소는 그대로이고, 학생들은 새로고침만 하면 됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
막혔을 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ Error: Not in a Firebase app directory
  → firebase.json 이 있는 폴더가 아닙니다.
     cd ~/todayhw  를 하고 다시 하세요.

■ Error: Failed to get Firebase project today-homework
  → 로그인이 안 됐거나 권한이 없습니다.
     firebase login --no-localhost  를 먼저 하세요.

■ Error: HTTP Error: 403
  → 로그인한 계정이 이 프로젝트의 주인이 아닙니다.
     파이어베이스 콘솔을 만들 때 쓴 계정으로 로그인했는지 확인하세요.

■ found 0 files in public
  → 파일이 안 올라갔습니다. 3단계를 다시 하세요.
     ls ~/todayhw/public  로 index.html 이 있는지 확인.

■ 주소는 나왔는데 "Site Not Found" 가 뜬다
  → 올라가는 데 1~2분 걸릴 수 있습니다. 잠시 뒤 새로고침.

■ 그래도 안 되면
  검은 창에 나온 내용을 그대로 복사해서 보내주세요.
