# 인터넷 주소 만들기 (10분)

시범 운영을 하려면 학생들이 접속할 주소가 필요합니다.
파이어베이스 호스팅으로 무료 주소를 만들 수 있고, 준비는 다 해뒀습니다.

주소는 `https://today-homework.web.app` 형태로 나옵니다.

---

## Cloud Shell에서 (제일 간단)

[console.cloud.google.com](https://console.cloud.google.com) 오른쪽 위
터미널 아이콘(>_)을 눌러 Cloud Shell을 엽니다.

### 1. 이 저장소 받기

```bash
git clone https://github.com/k1585/dodgeball-timer02.git
cd dodgeball-timer02/배포
```

비밀번호를 물으면 깃허브 아이디와 토큰을 넣으세요.

### 2. 파이어베이스 도구 설치 (전에 했으면 건너뛰기)

```bash
npm i -g firebase-tools
firebase login --no-localhost
```

### 3. 올리기

```bash
firebase deploy --only hosting
```

끝나면 `Hosting URL: https://today-homework.web.app` 이 나옵니다.
**그 주소가 앱 주소입니다.**

---

## 앱을 고친 뒤 다시 올릴 때

`오늘의숙제.html`을 고쳤다면 `배포/public/index.html`에도 같은 내용을
넣어야 합니다.

```bash
cd dodgeball-timer02
git pull
cp 오늘의숙제.html 배포/public/index.html
cd 배포
firebase deploy --only hosting
```

---

## 보안 규칙도 같이 올리려면

```bash
firebase deploy --only firestore:rules
```

`배포/firestore.rules`에 지금 쓰는 규칙이 들어 있습니다.
콘솔에 붙여넣는 것과 같은 결과입니다.

---

## 확인할 것

주소가 나오면 **휴대폰에서 직접 열어 보세요.**

- 선생님 계정으로 로그인되는지
- 사진 촬영 버튼이 동작하는지 (이건 주소가 있어야만 됩니다)

카메라는 보안 연결(https)에서만 열리는데, 파이어베이스 호스팅 주소는
https라서 문제없습니다.
