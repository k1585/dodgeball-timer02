「오늘의 숙제」 선생님용 사용 안내서

학생이 숙제를 사진으로 올리면 선생님이 확인하고 승인하는 앱입니다.

시범 운영용 · 2026년 9월

전체 흐름은 다섯 단계입니다.
가입하기 → 반 만들기 → 반 코드를 학생에게 알려주기 → 숙제 내기 → 제출 확인하고 승인하기

1. 가입하고 로그인하기

1선생님 선택하기

앱을 열고 시작하기를 누르면 역할을 고르는 화면이 나옵니다. 선생님을 누르세요.

2처음이면 회원가입

이름과 비밀번호를 넣고 가입 완료를 누릅니다.

  • 비밀번호는 8자 이상이어야 합니다
  • 눈 모양(👁) 버튼을 누르면 입력한 비밀번호를 확인할 수 있습니다
이름은 나중에 바꿀 수 없습니다. 학생들이 알아볼 수 있는 이름으로 가입해 주세요.

3다음부터는 로그인

가입을 마치면 처음 화면으로 돌아갑니다. 같은 이름과 비밀번호로 로그인하세요.

2. 반 만들고 코드 알려주기

4반 추가하기

로그인하면 이 화면이 나옵니다. 반 추가하기를 누르세요.

5반 이름 정하기

학생들이 알아볼 수 있는 이름을 적습니다. 예: 중2 영어 A반

6반 코드 확인 — 가장 중요

반을 만들면 여섯 자리 코드가 나옵니다.

이 코드를 학생들에게 알려주세요. 학생은 이 코드를 넣어야 반에 들어올 수 있습니다.
코드는 나중에 반 관리 화면 맨 위에서 다시 볼 수 있고, 복사 버튼으로 복사해 메시지로 보낼 수 있습니다.

3. 숙제 내기

7날짜를 고르고 숙제 만들기

반 관리 → 반을 누르고 → 숙제 관리 탭으로 갑니다.

  • 달력에서 제출 기한 날짜를 먼저 고릅니다
  • + 숙제 만들기를 누릅니다
  • 숙제 이름과 설명(선택)을 적고 만들기

8만든 숙제 확인

만든 숙제가 아래에 쌓입니다. 달력의 날짜 아래 점은 그날 숙제가 있다는 표시입니다.

잘못 만들었으면 삭제를 누르면 됩니다.

숙제를 삭제하면 학생들이 그 숙제에 올린 사진도 함께 지워집니다.

4. 학생 확인하기

9들어온 학생 보기

학생 관리 탭에서 반에 들어온 학생 명단을 볼 수 있습니다. 학생이 코드를 넣고 들어오면 자동으로 추가됩니다.

이름이 같은 학생이 있으면 두 번째 학생부터 01, 02 번호가 자동으로 붙습니다.

5. 제출 확인하고 승인하기

10숙제 현황에서 승인·반려

숙제 현황 탭입니다. 여기서 대부분의 일이 이루어집니다.

  • 학생 이름을 누르면 올린 사진을 크게 볼 수 있습니다
  • 확인했으면 승인, 다시 해야 하면 반려
  • 위쪽 칸으로 전체 / 승인요청 / 미제출 / 제출완료를 걸러 볼 수 있습니다
  • 날짜별로 보기를 켜면 날짜마다 묶어서 보여줍니다
탭 옆의 빨간 숫자는 아직 확인하지 않은 제출물 개수입니다.

6. 달력으로 한눈에 보기

11전체 반 일정

아래 달력을 누르면 맡은 반 전체의 숙제와 일정을 한 번에 볼 수 있습니다.

+ 일정 추가로 시험일 같은 일정도 올릴 수 있고, 학생들 달력에도 노란 점으로 표시됩니다.

자주 묻는 질문

질문답
학생이 반 코드를 잊었어요반 관리 화면 맨 위에 코드가 늘 보입니다. 복사를 눌러 다시 보내주세요.
학생이 비밀번호를 잊었어요담당자(김주원)에게 알려주시면 초기화해 드립니다.
반려하면 학생은 어떻게 되나요그 숙제가 다시 미제출로 바뀌어, 학생이 사진을 다시 올릴 수 있습니다.
사진이 안 올라간대요휴대폰 저장 공간이 부족할 수 있습니다. 앱이 안내 창을 띄워줍니다.
이름을 잘못 적고 가입했어요이름은 바꿀 수 없습니다. 담당자에게 알려주시면 계정을 지우고 다시 가입하시면 됩니다.
