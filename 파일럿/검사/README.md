흉내가 아니라 실제로 계정을 만들고, 사진을 올리고, 끝나면 지웁니다.

## 돌리는 법

```bash
# 1) 앱을 띄운다 (저장소 맨 위에서)
python3 -m http.server 8777 &

# 2) 전부 돌린다
cd 파일럿/검사 && ./runall.sh

# 3) 결과 보기
for t in e2e2 e2e5 e2e6 e2e7 e2e8 e2e9 e2e10 e2e11 e2e12 e2e13 attack; do
  echo -n "$t "; grep -E '^🎉|^⚠️|^❌' $t.out | tail -1
done
```

`playwright` 가 필요합니다. `fbsdk/` 폴더에 파이어베이스 SDK 사본이 있어야
`fblaunch.js` 가 동작합니다(이 환경의 프록시 때문이며, 제품 문제가 아닙니다).

## 검사를 막는 두 가지

진짜 사용자에게는 맞는 동작인데 검사에서는 화면을 덮어 버리는 것이 둘 있어서,
`fblaunch.js` 가 검사에서만 치워 줍니다.

* **처음 쓰는 사람 안내(손전등)** — 안내 자체를 보는 `e2e12` 만 `{ tour:true }`.
* **관리자 공지 팝업** — 공지를 보는 `e2e13` 은 필요한 대목에서만
  `window.__keepSys` 로 잠깐 켭니다.

안내는 '뜨면 닫는다'만으로는 모자랐습니다. 비밀번호를 정하는 창이 떠 있으면
안내가 최대 30초까지 기다렸다가 **뒤늦게** 시작하는데, 그때 검사가 보고 있던
화면을 안내가 다른 데로 넘겨 버립니다(실제로 `e2e11` 이 이것 때문에 한 번
깨졌습니다). 그래서 지금은 아예 시작하지 못하게 막습니다.

## 왜 전부 한꺼번에 돌리는가

`attack.js` 는 한동안 이 목록에서 빠져 있었습니다. 제일 중요한 검사인데도요.
그 사이에 보안 규칙을 여러 번 고쳤으니, 구멍이 다시 생겼어도 아무도 몰랐을 겁니다.

**안 도는 검사는 통과하지도 실패하지도 않습니다. 그냥 없는 것과 같습니다.**
사람이 "이건 돌려야지" 하고 고르기 시작하면 반드시 빠지는 게 생기므로,
`runall.sh` 하나로 전부 돌립니다.
