# 자동 점검 9종

고칠 때마다 전부 돌립니다. **진짜 파이어베이스 서버에 붙어서** 돕니다 —
흉내가 아니라 실제로 계정을 만들고, 사진을 올리고, 끝나면 지웁니다.

| 파일 | 무엇을 보는가 | 항목 |
|---|---|---|
| `e2e2.js` | **전체 흐름** — 창 두 개를 다른 기기로 두고 가입 → 반 만들기 → 계정 발급 → 숙제 → 제출 → 사진 열람 → 승인 → 새로고침 후에도 남는지 | 20 |
| `e2e5.js` | 로딩 표시, 로그아웃 위치, 마이페이지, 아이디 변경 | 16 |
| `e2e6.js` | 구글 로그인 — 계정 만들기, 오류 갈래, 학생 화면에 영향 없는지 | 27 |
| `e2e7.js` | 앱처럼 띄우기, 엑셀 저장, 반려→복귀, 달력 색, 승인→완료, 마감, 계정 삭제 비번 | 31 |
| `e2e8.js` | 진행 바 제거, 반 코드 제거 | 16 |
| `e2e9.js` | 로그아웃 확인창, 공지, 구글 나이 확인, 첫 로그인 아이디 변경 | 17 |
| `e2e10.js` | 일정 저장, 숙제 수정, 제출자 있으면 못 고침, 삭제 확인창 | 12 |
| `e2e11.js` | 승인 완료 칸 → 지난 숙제 이동, 비었을 때 안내, 달력 동그라미 | 9 |
| `attack.js` | **권한** — 남의 제출물·사진 읽기, 자기 숙제 스스로 승인, 남의 반 고치기가 거부되는지. 반대로 담당 선생님과 본인은 되는지 | 15 |

합계 **164개**.

## 돌리는 법

```bash
# 1) 앱을 띄운다 (저장소 맨 위에서)
python3 -m http.server 8777 &

# 2) 전부 돌린다
cd 파일럿/검사 && ./runall.sh

# 3) 결과 보기
for t in e2e2 e2e5 e2e6 e2e7 e2e8 e2e9 e2e10 e2e11 attack; do
  echo -n "$t "; grep -E '^🎉|^⚠️|^❌' $t.out | tail -1
done
```

`playwright` 가 필요합니다. `fbsdk/` 폴더에 파이어베이스 SDK 사본이 있어야
`fblaunch.js` 가 동작합니다(이 환경의 프록시 때문이며, 제품 문제가 아닙니다).

## 왜 전부 한꺼번에 돌리는가

`attack.js` 는 한동안 이 목록에서 빠져 있었습니다. 제일 중요한 검사인데도요.
그 사이에 보안 규칙을 여러 번 고쳤으니, 구멍이 다시 생겼어도 아무도 몰랐을 겁니다.

**안 도는 검사는 통과하지도 실패하지도 않습니다. 그냥 없는 것과 같습니다.**
사람이 "이건 돌려야지" 하고 고르기 시작하면 반드시 빠지는 게 생기므로,
`runall.sh` 하나로 전부 돌립니다.
