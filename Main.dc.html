🎯 전체 시스템 구조

3개의 진입점
  • 마스터 모드: "만나서 반가워요" 5회 클릭 → 비번(04220) → 관리자 페이지
  • 선생님 모드: 역할선택 → 로그인/회원가입 → 이름+비번 → 반 관리
  • 학생 모드: 역할선택 → 로그인/회원가입 → 이름+비번 → 반 추가 → 숙제 관리

📊 마스터 페이지 (드롭다운 형식)

1
선생님 목록 (드롭다운)
→ 각 선생님 클릭하면 확장
2
선생님의 반 목록 (드롭다운)
→ 각 반 클릭하면 확장 (학생 목록 표시)
3
각 반의 학생 목록 (드롭다운)
→ 각 학생 클릭하면 확장 (올린 숙제 표시)
4
학생이 올린 숙제 목록
→ 숙제 제목, 설명, 상태 표시

🔐 회원가입/로그인 시스템

로그인 화면

  • 역할 선택 (선생님/학생) 버튼
  • 이름 입력 필드
  • 비밀번호 입력 필드
  • "로그인" 버튼
  • "회원가입" 버튼 (아래)

회원가입 화면

  • 이름 입력 필드
  • 비밀번호 입력 필드
  • 비밀번호 확인 입력 필드 (입력 오류 방지)
  • "가입완료" 버튼
⚠️ 비밀번호 규칙:
• 8글자 이상
• 특수문자, 영문, 숫자 모두 포함 필수

🎓 학생 화면 변경

1
로그인 후 반 목록 표시
기존 반 유지됨 (저번 로그인 때 등록된 반, 올린 숙제 등 모두 유지)
2
"+ 반 추가" 버튼
선생님이 제공한 반 코드 입력 (기존 회원가입 화면처럼)
3
반 추가 완료 후 홈 화면으로
추가된 반이 목록에 나타남

💾 데이터 구조 (로컬스토리지)

users
[{ id, name, password, role: "teacher"|"student", createdAt }, ...]
classes
[{ id, name, code, teacherId, students: [], homeworks: [], createdAt }, ...]
studentClasses
[{ studentId, classId }, ...] (나중에 여러 반 지원할 때 사용)
